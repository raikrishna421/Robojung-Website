# RoboJung Courses Website — Colorful Version

This version uses the RoboJung logo plus the robotics/AI workshop and instructor images.

## GitHub Pages
1. Create a GitHub repository, e.g. `robojung-courses`.
2. Upload **all files and the `assets` folder**.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → / (root)**.
5. Save and open the GitHub Pages URL.

## Important
Replace `YOUR_EMAIL@example.com` in `index.html` with the email address you want to receive demo enquiries.

You can edit course names, ages, descriptions and project names directly in `index.html`.
